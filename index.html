    📄 Importa Schede Tombe da PDF

    Carica uno o più PDF delle schede sepoltura compilate. I dati vengono estratti automaticamente e salvati come schede tombe — potrai verificarle prima del salvataggio definitivo.

    📥 Importa Schede US da Excel

    Carica un file .xlsx con le schede US (una riga per scheda) e importale nel cloud. Le schede esistenti con lo stesso numero US verranno aggiornate.

    ⚰ Importa Tombe da Excel

    Carica il file tombe_estratte.xlsx generato dallo script Python. Le tombe esistenti con lo stesso numero verranno aggiornate.

    📓 Importa Diari da JSON

    Importa diari di scavo dal file diari_importati.json generato dallo script Python.
